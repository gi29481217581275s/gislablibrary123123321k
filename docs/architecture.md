# Архитектура

```
Vue 3 + Vite             ASP.NET Core              PostgreSQL
localhost:5173  ───────► localhost:5000  ───────► localhost:5432
                  HTTP                    запросы к БД
                  POST /api/bookings
```

архитектура web-ИС семестра

## Почему нет стрелки браузер → PostgreSQL

Прямой стрелки от браузера к базе нет: иначе клиент получает доступ к данным
и обходит серверные правила (проверку полей, прав ролей, статусов). Все запросы
идут через ASP.NET Core, который валидирует данные и только потом обращается
к PostgreSQL.
