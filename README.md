# Веб-платформа бронирования книг и рабочих мест в библиотеке

**ФИО:** Петров Егор Васильевич  
**Группа:** ТРИС-2-23 
**Стек:** Vue 3 + ASP.NET Core + PostgreSQL  
**Статус темы:** заявка подана, ожидает утверждения  

## О теме

Система для бронирования библиотечных ресурсов (книг и рабочих мест).
Главный объект - бронь. Читатель создаёт бронь, библиотекарь назначает
ответственного и подтверждает выдачу, заведующий смотрит сводку.
